1. PROJEKTIN MECSUDU
================================================================================

Bu projet XAUUSD (qezme), EURUSD (evro/dollar), GBPUSD (funt/dollar) ve WTI
(neft) emeliyyatlar ucun Python dili ile yasatilmis, yengil, asagi gecikmeli ve
riyazi usuluyla yoxlanila bilen fundamental-texniki tisaret qarar sistemi
yaradmaqla baglidir.

Sistem real broker-e buyurtma gondermez. Yalnız analiz, tisaret plani,
simulyasiya ve audit aparir.

Əsas meselen:
- Xebrləri iktisadi sebəb-nəticə əlaqələri ilə təhlil etmək
- Real-time qiymət axınını qorumaq
- Deterministik texniki strategiya icra etmək
- Hər qərarı sonra yenidən qurmaq (audit)

================================================================================
2. ARXITEKTURA
================================================================================

Sistem "modulyar monolit" principio ile qurulmusdur. Yani eyni bir Python
paketi icinde ferqli modullar var, lakin mikroservis, mesaj ochagini və ya
aqir infrastuktur yox.

Əsas axin:

Market/Xebr Yemekleri → Dayamí Ingestion → Kanonik Məlumat → Fundamental +
Texniki Təhlil → Risk Qapıları → Qarar → Audit

Komponentlər:

a) Ingestion (Girme)
   - biquote SignalR WebSocket - real-time qiymət axını
   - biquote REST API - tarixچه, simvollar, xəbər, iktisadi takvim
   - fin-data MCP - 83 alət, 15 provayder (hisə, valyuta, kripto, SEC, kongre)
   - searxng MCP - veb axtarış və URL oxuma
   - OHLC qurucusu - tiklərdən yerli şam (M1, M5, M15, H1, H4, D1)

b) Pipeline (Bor)
   - Raw Journal (append-only) - xam hadisələrin yazılması
   - Validasiya - invariantlerin yoxlanılması
   - Kanonik Store (SQLite WAL) - təmizlənmiş məlumatın saxlama

c) Fundamental Mühürki
   - Yapay zeka: inclusionAI/Ling-3.0-flash (OpenRouter vasitəsilə)
   - Xəbər və takvim snapshot hazırlığı
   - Səbəb-nəticə zinciri qurulması
   - Hər aktiv üçün ayrı təsir qiymətləndirilməsi

d) Texniki Mühürki (Deterministik Python)
   - H1 bazar strukturı (güclü/zəif yüksek/düşük, eyni seviyyələr, trendu)
   - M15 RSI(14) - Wilder yumuşatma usulu
   - Şam patternləri (3-1, 1-1, 1-3, 3-3)
   - Giriş, dayanma (SL), çatdırma (TP1, TP2) hésablamaları
   - Risk/ödül (RR) nisbəti

e) Risk Mühürki
   - Qatı qapılar (AI onarla.equal olmaz)
   - spread, data quality, market saatləri, xəbər karantinası
   - minimum RR, gündəlik zərar limiti, maksimum iş sayısı

f) Qarar Mühürki
   - OPEN (təsdiqləndi), WAIT (gözləyiş), SKIP (red olundu)

g) Audit (Yaddaş)
   - Hər qərarın inputları, hesablamaları, AI cavabları, nəticələri saxlama

h) Axle-Axiom
   - Lean 4 ilə riyazi yoxlamalar (OHLC invariantları, RSI, RR, posición ölçüsü)

i) API
   - Minimal REST: /health, /metrics, /market/{symbol}, /candles/{symbol},
     /news, /calendar, /analysis/{symbol}, /decisions, /decisions/{id}

3. İŞLEME PRİNSİPLƏRİ
================================================================================

a) Hər komponent düşünülmüşdür ki başkasının xətası sessizcə digərində
   məlumat körünməsinə səbəb olmasın.

b) Hər tik analizdən əvvəl dayamí yaddaşa yazılır (WAL jurnal + SQLite).

c) Dublikat aşkın olunur (event_id + provayder simvolu + vaxt).

d) Boşluq (gap) aşkar olunarsa o interval tam hesablanmaz.

e) AI indi buyurtma vermir, yalnız təhlil edir. Hesablamalar (RSI, ATR,
   SL, TP, position ölçüsü) deterministik Python ilə edilir.

f) Qiymətlər float ilə, decimal ilə hesablanır ki riyazi xəta yox olsun.

g) Zaman damgaları (timestamps) audit məlumatından silinməz.

h) AI cavabında faktor, höhəmət, aksi sübutlar və ?
qeyd edilməlidir. AI gələcək qiymət istehsalı fact kimi təqdim etmez.

i) Qarar Yevlət: OPEN, WAIT, SKIP. OPEN broker buyurdu deyil,
   təyin edilən planıdır.
